# 📝 Markdown Previewer

A simple and interactive **Markdown Previewer** built with **React and TypeScript**.

The application allows users to write Markdown in a text editor and see the formatted result instantly in a live preview window.

This project was created as part of the **freeCodeCamp Front End Libraries certification**.

**🚀 [Live Demo](https://nda-kd.github.io/Markdown-Previewer/)**

---

## ✨ Features

* 📝 Write Markdown in a live editor
* 👀 Preview formatted Markdown instantly

* 🧩 Supports common Markdown syntax
* ⚛️ Built with React

## 📝 Supported Markdown

The previewer can render common Markdown elements, including:

### Headings

```markdown
# Heading 1
## Heading 2
### Heading 3
```

### Text Formatting

```markdown
**Bold text**

*Italic text*

~~Strikethrough~~
```

### Links

```markdown
[freeCodeCamp](https://www.freecodecamp.org/)
```

### Code

```markdown
`Inline code`
```

### Lists

```markdown
- Item one
- Item two
- Item three
```

### Blockquotes

```markdown
> This is a blockquote.
```

## ⚙️ How It Works

The application follows a simple real-time workflow:

```text
Markdown Input
      │
      ▼
React State
      │
      ▼
Markdown Parser
      │
      ▼
Formatted HTML
      │
      ▼
Live Preview
```

As the user types into the editor, the Markdown content is processed and rendered in the preview section.

## 🚀 Getting Started

### Prerequisites

You'll need:

* [Node.js](https://nodejs.org/)
* npm or Yarn

### Clone the Repository

```bash
git clone https://github.com/nda-kd/Markdown-Previewer.git
```

Navigate into the project directory:

```bash
cd Markdown-Previewer
```

### Install Dependencies

Using npm:

```bash
npm install
```

Or using Yarn:

```bash
yarn install
```

### Start the Development Server

```bash
npm start
```
